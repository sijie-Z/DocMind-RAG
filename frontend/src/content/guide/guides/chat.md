对话页是日常使用最多的页面：提问、切换模式、管理会话、上传附件、导出对话。

## 快速问答与深度分析

输入框上方有两个模式：

- **快速问答**：一次检索 + 一次生成，速度快，适合事实查询与文档定位。
- **深度分析**：走 PER Agent（规划、工具调用、反思），适合跨文档分析、多步推理。该模式强制使用 SSE 流式传输，不能切换到 WebSocket。

两个模式是同一个状态：输入框里的模式选择与传输设置弹层里的「Agent 模式」开关控制的是同一个布尔值。深度分析会在消息中展示思考过程、计划树、反思与运行报告，但不展示人工审批卡片（审批只在 Agent 工作台出现）。

## 会话管理

- 「新对话」只清空当前界面；会话记录在发送第一条消息时创建。
- 会话列表最多加载最近的 50 条，没有「加载更多」。
- 删除会话有二次确认，删除后不可恢复。
- 目前没有重命名会话的界面。
- 页头的「清空对话」只清空消息，不删除会话本身。

## 附件

- 附件选择器接受 `.pdf`、`.doc`、`.docx`、`.txt`、`.md`，单个文件上限 10MB，一次选择一个文件。
- 解析器实际只支持 `.docx`；选择 `.doc` 会在解析阶段失败，建议另存为 `.docx` 再上传。
- 支持拖拽文件到输入区，拖拽不经过选择器的格式过滤，但同样受 10MB 限制。
- 上传后先尝试 `parse-upload` 即时解析；失败则回退到文档上传接口并轮询索引状态。
- 附件状态会显示「上传中」「解析中」「索引中」「已就绪」「解析失败」，也兼容显示「等待处理」「已上传」等原始状态。
- 当附件已经进入知识库并拿到文档 ID 时，输入区会出现「仅附件模式」开关（默认关闭）。开启后回答严格限定在附件范围内；关闭时只在检索范围上绑定当前文档，不保证完全不使用其他上下文。

## 导出与流式控制

- 「导出对话」在浏览器端生成 Markdown 文件（文件名含会话标题与时间戳），包含来源引用；没有 PDF/Word/JSON 导出，也没有服务端导出接口。
- SSE 是默认且当前可用的传输方式；传输设置里虽有 WebSocket 选项，但当前版本切换后不会建立连接，请保持 SSE（企业防火墙环境同样走 SSE）。「流式响应」只控制是否逐字渲染，不改变传输方式。
- 生成过程中点「停止生成」会中断当前请求，已生成内容保留并标记为「已停止」。

## 隐私模式

隐私模式会对送入模型的检索上下文与问题做敏感信息脱敏（自动掩码）。它不会阻止会话消息落库，也不会关闭语义缓存或记忆写入（语义缓存默认关闭）；「深度分析」不走这个开关。组织设置可以关闭「允许隐私模式」，此时个人开关会置灰并提示「组织策略已禁用隐私模式」。
