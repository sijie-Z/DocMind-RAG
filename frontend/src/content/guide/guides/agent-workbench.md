Agent 工作台（路由 `/agent`）是观察和控制 PER Agent 的界面。它没有左侧菜单入口，通常从首页的「打开 Agent 工作台」卡片、通知或深链进入；对话页的「深度分析」也走同一套 Agent 能力。

## 工具配置

- 配置面板会拉取 `GET /agent/tools`，为每个工具提供开关，并显示名称、说明与「默认关闭」标签。
- 默认关闭的三个工具：`execute_python`、`execute_sql`、`mcp_call`。它们由服务端强制保持关闭，界面开关无法真正启用。
- 状态栏显示「工具: 已启用/总数」。
- 配置面板可设置审批模式；计划审批目前没有界面开关，只能通过服务端配置/接口设置（见「工具与人工审批」）。

## 人工审批

- 需要审批时，输入框上方出现审批卡片：显示工具名、风险级别（高/中/低/已超时）与参数摘要。
- 操作：批准、拒绝，可选填写「改指令 / 备注」。批准时该文本作为人工指导注入后续步骤；拒绝时作为备注。
- 计划审批开启时，会出现「计划待审批」卡片，可批准计划、编辑步骤或拒绝；等待期间输入框被禁用。

## 停止与恢复

- 运行中可点「停止」调用服务端取消接口；取消是协作式的，任务会在下一个步骤或工具检查点收敛为「已取消」，正在执行的工具或 LLM 调用不会被强行中断，界面有约 15 秒的收敛等待。
- 等待审批时输入区不显示停止按钮，请直接在审批卡片上批准/拒绝（服务端取消接口对等待审批的任务也会立即生效）。
- 刷新页面或重新打开任务时，会通过任务详情恢复现场（包括等待审批的卡片）。
- 目前没有「继续运行」按钮；要恢复执行，请在审批卡片上做出决定。

## 断点续跑

- 审批暂停、计划审批暂停与运行中的关键步骤都会写入检查点。
- 批准后后端从检查点恢复，并重新执行当前步骤（至少一次语义）；拒绝则把结构化失败交给反思阶段。
- 刷新页面后，任务详情会恢复等待审批的现场，因此「刷新后继续审批」就是当前的断点续跑入口。
- 已取消或已失败的任务不能从界面续跑；需要重新发起任务。

## 回放与任务记录

- 回放只在运行走到收尾并保存了执行上下文时存在；取消或异常中断通常没有回放，少数失败（例如最终 LLM 调用失败）仍可能保留回放。
- 最近一次任务完成后，回答下方会出现「查看回放」（以服务端返回的 `has_replay` 为准）；页头「任务记录」弹层列出最近 10 个任务，可对有回放的任务点「回放」。
- 回放是只读播放：时间线展示每步工具、耗时、结果摘要、关键发现与决策、失败信息；不会重新执行任务。
- 回放数据默认保留 7 天（Redis）；本地文件兜底没有过期策略，以部署配置为准。过期后接口返回 404（REPLAY_NOT_FOUND），界面显示诚实的空态。
- 也可以用 `?id=<task_id>` 深链直接打开某个任务的回放。

## 会话

- 可新建会话、删除当前会话（有确认）。
- 「清空」只清空当前界面消息，不删除服务端历史。
- 目前没有重命名会话的界面。
