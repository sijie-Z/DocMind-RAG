Agent 可以调用代码执行、数据库查询、联网搜索等工具。部分工具风险较高，因此 DocMind 提供了人工审批（HITL，Human-in-the-Loop）机制：在工具真正执行前暂停任务，等待人做决定。

## 审批模式

在 Agent 工作台的工具配置里可以选择：

- **不审批**：所有工具直接执行。
- **仅高危工具审批（默认）**：只有被判定为高风险的调用才暂停。
- **所有工具调用审批**：任何工具调用都暂停。

风险判定顺序是：工具自带的风险级别 → 中央风险表 → 语义兜底 → 默认低风险。中央表里 `execute_python`、`execute_sql`、`mcp_call` 为高风险；`fetch_webpage`、`web_search`、`deep_research`、`delegate_subtask` 为中风险。默认模式下只拦截高风险工具。

需要注意：三个高风险工具由服务端强制保持关闭——即使界面开关打开，服务端也会把它们合并回禁用列表，工具调用会被拒绝。因此默认配置下审批通常不会触发；要验证审批流程，请切换到「所有工具调用审批」，此时其他工具调用会触发审批卡片。部署方如需启用这些工具，必须在服务端层面调整。

## 审批如何工作

- 审批绑定到「工具名 + 参数指纹」（参数 JSON 的 SHA-256 前 16 位），同一次运行内同一组调用的决定是粘性的，不会反复询问。
- 批准：记录决定并恢复任务，该步骤会重新执行一次（至少一次语义），随后允许调用工具。
- 拒绝：工具不执行，形成结构化失败 `approval_denied` 交给反思阶段；同一组调用不会再次询问。
- 批准时可以填写「改指令」：会作为人工指导注入后续步骤的提示词。
- 默认审批超时为 0，表示一直等待；如果部署方设置了超时，超时会在审批读取/决策时判定（不是定时器），审批卡片会失效并按失败（`approval_timeout`）处理，不会被记为拒绝。

计划审批是另一套独立机制（默认关闭，且当前界面没有开关，只能通过服务端配置/接口开启）：开启后，每次规划产出计划都需要批准、编辑步骤或拒绝。

审批卡片只出现在 Agent 工作台；对话页的「深度分析」不展示审批卡片。

## 依据（代码事实）

- `backend/app/agent/approval.py`（协议、风险表、参数指纹）
- `backend/app/agent/config.py`（审批模式与超时默认值）
- `backend/app/agent/executor.py`（执行前审批预检、强制禁用工具）
- `backend/app/agent/loop.py`（暂停与检查点）
- `backend/app/agent/checkpoint.py`（审批决定与恢复、超时判定）
- `backend/app/api/v1/endpoints/agent.py`（审批接口、禁用工具合并）
- `frontend/src/components/agent/ApprovalCard.vue`（审批卡片）
