## 2. 复现命令

在 `backend/` 目录下执行。ES 地址经 `ELASTICSEARCH_HOSTS` 环境变量（或 `--es-hosts`
参数）注入；live 嵌入所需环境变量（`EMBEDDING_API_URL`、`EMBEDDING_API_KEY`
占位值、`EMBEDDING_MODEL=qwen3-embedding:0.6b`、`VECTOR_DIMENSION=1024`）按
`backend/evals/runner.py` 文件头部注释配置：

```bash
cd backend

# 1) 先删后建评测索引，并用真实嵌入写入固定语料
python -m evals seed --recreate --embedding live \
  --golden evals/golden_set/clause_set_v1_5.json \
  --index docmind_knowledge_eval_live_v1 --org-id 9901

# 2) 对 80 条 golden 跑 hybrid 检索并产出报告
python -m evals run --embedding live --retriever hybrid \
  --golden evals/golden_set/clause_set_v1_5.json \
  --index docmind_knowledge_eval_live_v1 --org-id 9901
```

报告默认输出到 `backend/evals/reports/latest.{json,md}`；本次运行的归档副本见第 5 节。

| 指标 | 值 | 95% CI（Wilson） | 说明 |
|---|---|---|---|
| ClauseHit@1 | 75.0% | - | 条号定义位命中（首位） |
| ClauseHit@3 | 86.7% | - | 同上（前三） |

| NearMiss@5 | 21.7% | - | 误召相邻条比例（cap，越低越好；n=60） |
| MRR | 0.8125 | - | 首个 gold 名次倒数均值 |
| EmptyAcc | 100.0% | [83.9%, 100.0%] | 负例返回空的比例（n=20） |

60 条正例中 7 条在 top-5 内未命中 gold（ClauseHit@5 = 53/60）；20 条负例全部
正确返回空。逐条 PASS/FAIL 与失败样本见第 5 节的原始报告。

## 4. 与 fake 门禁、旧 live 的口径差异

| 运行 | 日期 | 题集 | 嵌入 | ClauseHit@1 / @3 / @5 / MRR | 口径 |
|---|---|---|---|---|---|
| CI fake 门禁（v1.5） | 2026-10-24 | 80 条（60 正 + 20 负） | 确定性伪嵌入 `hash-bigram-char-v1`（dim=256） | 70.0 / 76.7 / 80.0 / 0.74 | 防回归的工程门禁基线，是保守下界；**不是**检索质量数字 |
| 旧 live（Eval v1） | 2026-10-09 | 28 条（25 正 + 3 负） | Qwen3-Embedding 0.6B（真实 ES） | 80 / 84 / 84 / 0.82 | v1 历史口径；题集不同，**不可**与 80 条直接比较 |
| **本次 live（Eval v1.5）** | 2026-10-25 | 80 条（60 正 + 20 负） | 本机 Ollama `qwen3-embedding:0.6b`（1024 维，真实 ES） | **75.0 / 86.7 / 88.3 / 0.8125** | live embedding + hybrid + LLM 关闭；**非 rerank** |

- fake 门禁的用途是「确定性、可复现的回归保护」：它保护检索管道的行为面，不承担
  检索质量对外的职责；`mode=fake` 与 `mode=live` 的数字不可混写。
- Eval v1（28 条）与 Eval v1.5（80 条）语料与题集均不同（v1.5 语料扩到 8 文件），
  任何跨版本比较只能作方向性参考。

## 6. 局限性

1. **无真实 rerank。** 本文只是 live embedding；仓库内 rerank live 报告仍为
   `status=unavailable` 占位，未测量任何 rerank 指标。
2. **无 LLM 辅助。** 查询改写 / HyDE 关闭——测的是纯检索管道；生成层指标
   （Citation Accuracy 等）不在本评测范围内。
3. **本机 Ollama + 单机 ES。** 不是云托管 / 集群环境；数字绑定当次物理索引状态
   （先删后建），换机器、换模型版本或换索引状态需重测。
4. **样本量有限。** 正例 60 条，ClauseHit@5 的 Wilson 95% CI 为 77.8–94.2%；
   对外引用必须同时标注 mode=live、日期与模型。
5. **单数据集版本。** 仅 `docmind_clause_v1_5` v1；与 Eval v1 的 28 条及 CI fake
   数字均不可混比。
